## 为什么是"原始 API"而不是"框架"

过去 3 年 AI 工程化最显著的"陷阱"是：**框架封装掩盖了基础模型的真实接口**。

`1.` **LangChain / LlamaIndex 等框架提供"高级抽象"**，但这些抽象有自己的假设（chain of thought 怎么组织、retrieval 怎么排序、tool call 怎么传参）。当用户的实际需求与框架假设不一致时，**调试成本反而更高**。

`2.` **框架版本变化频繁**。2024-2026 年 LangChain 经历了多次重大 API 重构，2024 年中期的代码到 2026 年已经不能直接运行。**框架学习的时间成本是持续支出**。

`3.` **基础模型 API 本身在变稳定**。OpenAI API 模式（messages、tools、temperature、stream、response_format）从 2024 年到 2026 年相对稳定，**学一次能用三年**。

这套 Colab 笔记本选"原始 API"是为了把学习者的时间投在**长期资产**上，而不是**短期易变工具**上。
