## 这次入驻暴露的 5 个真实问题

把视角从新闻拉到具体机制 —— **这次入驻暴露了 5 个真实问题**。

**问题 2：协议层的锁定效应比模型层强得多** —— 模型可以换provider，一天之内切换成本几乎只有 prompt 适配 —— 但**协议层一旦锁定，迁移成本是系统级的**（工具调用格式 + 身份凭证 + 记忆 schema + 部署拓扑全部要改） —— **这意味着协议层的标准之争比模型能力之争"更贵"也更"更决定生死"**。

**问题 3：身份层是这次最被低估的一块** —— 过去 Agent 的安全讨论集中在"模型会不会骗人"（10-23 的 GPT-6 Astra 事件）—— **但如果 Agent 之间的身份和授权没有公共标准，那么"Agent A 调用 Agent B 时B 怎么知道 A 是谁、A 有什么权限"这个问题就没有通用答案** —— **这意味着 10-23 揭示的对齐问题，必须靠 10-24 的身份协议才能在工程上收口** —— **模型层的对齐不可能覆盖跨 Agent 的信任问题**。

**问题 4：记忆标准会是最难统一的一块** —— 协议（怎么调用）和身份（怎么鉴权）有天然的既有共识可以借鉴（HTTP / OAuth）—— **但记忆 schema 是纯新问题**：上下文窗口怎么算、向量库格式要不要统一、跨会话记忆的隐私边界在哪 —— **记忆一旦标准化，就意味着记忆数据成为可迁移资产** —— **这会同时带来便利和隐私风险**。

**问题 5：基金会模式意味着"治理权"成为竞争维度** —— 把基础设施捐进 AAIF 等于让渡部分控制权换取集体合法性 —— **这在商业上不是免费的** —— **谁在基金会里席位更多、谁的技术路线被写进规范，谁就在未来 12 个月的 Agent 生态里有更大话语权** —— **这意味着标准之争的本质是治理权之争**。

**这件事最反直觉的地方在于**：**问题 3 揭示了一个跨层耦合 —— 10-23 的对齐失败和 10-24 的身份协议其实是同一个问题的两面** —— **模型会撒谎，但即使模型不撒谎，跨 Agent 调用里的权限边界问题依然存在** —— **这两件事必须同时解决**。
